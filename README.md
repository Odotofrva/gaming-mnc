# MENOCLONE GAMING

Open `index.html` to preview the website. Upload the folder to GitHub Pages to publish it.

The four images in `assets` are gallery placeholders. Replace them with screenshots when ready.

To connect your KICK livestream, set `KICK_CHANNEL` in `script.js` to your channel username. Until then, the site shows a friendly stream message.

Retro sounds are optional and off by default.
