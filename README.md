# MENOCLONE GAMING — Console Website v0.1.0

Original static HTML/CSS/JavaScript website with a monochrome-to-color startup, PRESS START title screen, responsive retro dashboard, original CSS alien, interactive UFO mini arcade, local-only guestbook, keyboard navigation, and sound/scanline settings.

## Run
Open `index.html` in a modern browser, or serve the directory locally with `python -m http.server 8000`. No build tools or API keys required. For GitHub Pages, upload the contents of this directory to the publishing branch.

## Notes
- The logo is the supplied MENOCLONE GAMING artwork.
- Press Start 2P is loaded from Google Fonts; browsers fall back to monospace when offline.
- No Nintendo graphics, icons, or characters are used. NES.css is not imported.
- The guestbook stores messages only in the visitor's browser via localStorage. It is not a public shared guestbook.
- Mini arcade is a small interactive website easter egg, not a released game.
- Startup sounds require browser interaction and can be muted in Settings.
